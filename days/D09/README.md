## 第 2 步：写代码（约 2 小时）

合上书，按下面的顺序写，每写完一个函数就运行一次测试：

1. 写 `paren`：左括号入栈，右括号时栈顶必须是对应的左括号。
2. 写 `isStackPermutation`：模拟 1..n 依次入栈，看能不能按 B 的顺序出栈。
3. 写 `evaluateRPN`：读到数就入栈，读到运算符就弹出两个数（`!` 只弹一个）计算后入栈。
4. 写 `evaluate`：照书上的算法，运算数栈 + 运算符栈 + 优先级表。优先级表可以照书上的抄，注意这里支持 `+ - * / ^ !` 和括号，`^` 左结合。每输出一个数或运算符，就把它追加到 rpn（各项之间一个空格）。
5. 运行 `tools/test.sh ch04_stack D09`。随机表达式那个用例会报出算错的表达式，拿它单独调试。

全部完成时，这 5 个用例都显示 `[通过]`，每个测试程序的最后一行是 `通过 …，失败 0，待实现 0`。还没写的函数显示黄色的 `[待实现]`；写错的显示红色的 `[失败]`，下面跟着出错的那行测试代码和两边的实际值。

调试提示：

- 数可以是小数（如 2.5）：读数时要连同小数点一起读完。
- `2^3!` 应等于 64（先算阶乘），`2^3^2` 应等于 64（左结合）。
- rpn 末尾不要多空格；测试是把你的 rpn 重新求值来检查的，所以只要顺序对、空格分隔就行。
