## 第 2 步：写代码（约 2 小时）

合上书，按下面的顺序写，每写完一个函数就运行一次测试：

1. 写 `Queue` 的三个函数（队头在列表首端）。运行 `tools/test.sh ch04_queue Queue`。
2. 写 `placeQueens`：栈里第 i 个元素是第 i 行皇后的列号；当前列冲突就右移，越界就出栈回溯。不能用递归。
3. 写 `labyrinth`：栈里存路径上的格子，以及每个格子下一个要试探的方向；四个方向都试过就出栈。栈里剩下的就是路径。
4. 写 `bankSimulate`：严格按 stack_apps.h 里写的每分钟两步规则模拟，每个窗口一个你自己的 Queue。
5. 运行 `DSA_STRICT=1 tools/test.sh ch04`：ch04_stack 和 ch04_queue 两个文件共 15 个用例全部通过。
