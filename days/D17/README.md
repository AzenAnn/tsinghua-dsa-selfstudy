## 第 2 步：写代码（约 2 小时）

合上书，按下面的顺序写，每写完一个函数就运行一次测试：

1. 写 `PFS(s, pu)`：s 的优先级设为 0；每次对刚访问的顶点的所有邻居调用 `pu(this, s, w)`，再扫描所有顶点，选优先级最小的未发现顶点访问，把它和 parent 之间的边标为 Tree。
2. 写 `pfs(s, pu)`：像 bfs 一样覆盖全图。
3. 写 `PrimPU`：邻居 u 未发现、且边权小于 u 当前的优先级时，更新 u 的优先级和 parent。
4. 写 `DijkPU`：把“边权”换成“priority(v) + 边权”。
5. `prim`、`dijkstra` 各一行。运行 `DSA_STRICT=1 tools/test.sh ch06`，16 个用例全部通过。
