## 第 2 步：写代码（约 2 小时）

合上书，按下面的顺序写，每写完一个函数就运行一次测试：

1. 写 `hashCode(string)`：多项式散列，h = h × a + c，a 取一个奇数（比如 131）。
2. 写构造和析构：表长取 `primeNLT(c)`（已写好）。
3. 写 `probe4Hit`：沿查找链走，遇到关键码相同的桶返回；遇到既空又没有懒惰删除标记的桶，说明不存在，返回这个桶。每检查一个桶 `probes_++`。
4. 写 `probe4Free`：沿查找链找第一个空桶（懒惰删除的桶也可以用）。
5. 写 `put`、`get`、`remove`、`rehash`：(N + L) × 2 > M 时重散列，新表长取不小于 4N 的素数，把旧词条逐个重新插入。
6. 运行 `tools/test.sh ch09 D27`，5 个用例全部通过。
