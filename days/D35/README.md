## 第 2 步：写代码（约 2 小时）

合上书，按下面的顺序写，每写完一个函数就运行一次测试：

1. 写 `majority`：先摩尔投票选出候选者，再数一遍它出现的次数验证。
2. 写 `median`：返回合并后秩为 ⌊(n1+n2)/2⌋ 的元素；用“每次排除 k/2 个”的方法求两个有序序列的第 k 小，不能真的合并。
3. 写 `quickSelect`：反复做 partition，只进入包含 k 的那一侧。
4. 写 `linearSelect`：5 个一组排序取中位数，递归求中位数的中位数 M，按小于、等于、大于 M 分成三份，递归进入包含 k 的那一份。
5. 运行 `tools/test.sh ch12 D35`。
