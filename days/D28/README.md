## 第 2 步：写代码（约 2 小时）

合上书，按下面的顺序写，每写完一个函数就运行一次测试：

1. 写 `countingSort`：统计次数、求前缀和、按顺序放回（稳定）。
2. 写 `radixSort`：以 8 位为一位，做 4 趟稳定的计数排序（从低位到高位）。
3. 写 `bucketSort`：n 个桶，元素 x 放进第 ⌊x·n⌋ 个桶，每个桶内插入排序，再依次连接。
4. 写 `maxGap`：n 个数放进 n+1 个等宽的桶，只记录每个桶的最小值和最大值；答案是相邻非空桶之间“后桶最小值 − 前桶最大值”的最大者。注意用 long long 防溢出。
5. 运行 `DSA_STRICT=1 tools/test.sh ch09`，11 个用例全部通过。
