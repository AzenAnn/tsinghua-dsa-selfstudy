## 第 2 步：写代码（约 2 小时）

合上书，按下面的顺序写，每写完一个函数就运行一次测试：

1. 写 `tSort`：DFS，访问完一个顶点就把它压栈；遇到 Discovered 的邻居说明有环，返回 false；最后依次出栈就是拓扑序。
2. 写 `tSortKahn`：先把入度为 0 的顶点入队，每出队一个，就把它邻居的入度减 1，减到 0 的入队。
3. 写 `bcc`：DFS 的同时维护 hca（可以借用 fTime 字段存），用一个栈记录访问过的顶点；当孩子 u 的 hca 不小于 v 的 dTime 时，弹栈到 u 为止，得到一个双连通域，v 是关节点（v 是根时，要有至少两个孩子才是关节点）。
4. 运行 `tools/test.sh ch06 D16`。
