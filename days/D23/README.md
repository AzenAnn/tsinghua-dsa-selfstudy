## 第 2 步：写代码（约 2 小时）

合上书，按下面的顺序写，每写完一个函数就运行一次测试：

1. 写 `remove`：找到 e 所在节点；如果不是叶子，找右子树最左的叶子，用它的第一个关键码顶替 e；然后在叶子里删除关键码和一个空孩子，`solveUnderflow`。
2. 写 `solveUnderflow(v)`：孩子数不少于 ⌈m/2⌉ 就结束；v 是根时，如果它已经没有关键码但有孩子，就让唯一的孩子当新根。否则先试左兄弟、再试右兄弟（兄弟的孩子数多于 ⌈m/2⌉ 才能借，借的时候关键码经过父节点“旋转”），都不行就和兄弟合并（父节点下来一个关键码），再对父节点递归。
3. 运行 `DSA_STRICT=1 tools/test.sh ch08_btree`，5 个用例全部通过。
