# 综合项目

把前面自己实现的结构用起来，做两个完整的小工具。每个项目放在自己的目录里，带一个 `CMakeLists.txt`，顶层的 CMake 会自动把它收进来。

## 一、minikv：命令行键值库（D38）

用自己的 B-树（或跳表）做存储，从标准输入读命令：

```text
put <key> <value>     插入或覆盖
get <key>             查询，不存在输出 (nil)
del <key>             删除
range <lo> <hi>       按键的顺序输出 [lo, hi) 里的所有键值对
size                  当前键的个数
```

要求：

- `put`、`get`、`del` 都是 O(log n)，`range` 是 O(log n + 输出的个数)；
- 写一个随机命令生成器，和用 `std::map` 写的参考实现对拍 10⁵ 条命令；
- 选做：`save <文件>` 和 `load <文件>`，把数据持久化到磁盘。

## 二、huffzip：Huffman 文件压缩（D39）

```bash
huffzip c <输入文件> <输出文件>     压缩
huffzip d <输入文件> <输出文件>     解压
```

要求：

- 用自己的 Huffman 树、左式堆和位图实现，文件头里存频率表；
- 随机文件、空文件、只有一种字节的文件、比较大的文本文件，压缩再解压都要和原文件逐字节一致；
- 在 README 里记录几类文件的压缩率，并和 `gzip` 对比。
