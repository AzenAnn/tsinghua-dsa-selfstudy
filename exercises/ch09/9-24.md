## 题目

习题[4-18]（100页）曾指出，同一整数可能同时存在多个费马-拉格朗日（Fermat-Lagrange）分解，其中，四个整数之和最小者称作最小分解。比如：101  = 02 + 02 + 12 + 102 = (0, 0, 1, 10) = 02 + 12 + 62 + 82 = (0, 1, 6, 8) = 02 + 22 + 42 + 92 = (0, 2, 4, 9) = 02 + 42 + 62 + 72 = (0, 4, 6, 7) = 22 + 52 + 62 + 62 = (2, 5, 6, 6) 其中(0, 0, 1, 10)即为101的最小费马-拉格朗日分解，因为组成它的四个整数之和11为最小。

a） 试设计并实现一个算法，对任何整数n > 0，输出[1, n]内所有整数的最小费马-拉格朗日分解；

b） 你的算法需要运行多少时间？空间呢？
