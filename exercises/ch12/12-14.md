## 题目

设使用Pratt序列：

```cpp
    H  =  { 1, 2, 3, 4, 6, 8, 9, 12, 16, ..., 2p3q, ... }
```

pratt 对长度为n的任一向量S做希尔排序。

试证明：

a） 若S已是(2, 3)-有序，则只需O(n)时间即可使之完全有序；

b） 对任何h  H，若S已是(2h, 3h)-有序，则只需O(n)时间即可使之h-有序；kprattkkk

c） 针对H序列中的前O(log2n)项，希尔排序算法需要分别迭代一轮；pratt

d） 总体的时间复杂度为O(nlog2n)。
