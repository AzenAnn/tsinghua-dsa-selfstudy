## 题目

考虑用向量存放一组字符串。为在其中进行二分查找，可依据字典序确定字符串之间的次序：设字符串a  =  aa...a 和 b  =  bb...b 12n12m 则a < b当且仅当n = 0 < m，或者a < b，或者a = b且a...a < b...b 11112n2m 也就是说，两个字符串之间的大小关系，取决于它们（按首字符对齐后）第一对互异的字符。

a） 试实现一个字符串类，并提供相应的比较器，或者重载对应的操作符；

b） 若共有n个字符串，二分查找的复杂度是否仍为O(logn)？
