## 题目

设B为A = { 1, 2, 3, ..., n }的任一排列。

a） 试证明，B是A的一个栈混洗，当且仅当对于任意1  i < j < k  n，P中都不含如下模式：

```cpp
   { ..., k, ..., i, ..., j, ...}
```

b） 若对任意1  i < j < n，B中都不含模式：

```cpp
   { ..., j + 1, ..., i, ..., j, ...}
```

则B是否必为A的一个栈混洗？若是，试给出证明；否则，试举一反例。

c） 若对任意1 < j < k  n，B中都不含模式

```cpp
   { ..., k, ..., j - 1, ..., j, ...}
```

则B是否必为A的一个栈混洗？若是，试给出证明；否则，试举一反例。
