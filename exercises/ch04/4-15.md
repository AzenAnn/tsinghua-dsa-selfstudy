## 题目

为判断包含多种括号的表达式是否匹配，可否采用如下策略：分别检查各种括号是否匹配；若它们分别匹配，则整体匹配试证明你的结论，或者给出一个反例。

a） 在表达式任意前缀中，左括号的数量都不少于右括号；

b） 整个表达式中，左括号与右括号数量相等。然而在有多种括号并存时，还需追加一条，以检查不同括号之间的相对位置：

x）在相互匹配的任何一对括号之间，则各种括号都是匹配的。否则，即便每种括号均各自匹配，但不同括号之间仍可能存在相互“交错”的现象。比如，以下即是一个反例：

```cpp
(  [  {  )  ]  }
```
