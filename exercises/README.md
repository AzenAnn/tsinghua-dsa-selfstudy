# 教材课后习题

每章一个目录，文件名用教材的题号，例如第2章第12题是 `exercises/ch02/2-12.md`。编程题另外写 `2-12.cpp`，在 md 里说明。

```bash
python3 tools/new.py exercise ch02 2-12          # 新建 2-12.md，并在 ch02/README.md 的表格里加一行
python3 tools/new.py exercise ch02 2-12 --code   # 另外建 2-12.cpp
```

每道题写三部分：

1. **题目要点**：用自己的话概括，不照抄原题；
2. **解答**：证明题写完整的证明，计算题写过程；
3. **反思**：这道题考的是哪个知识点，第一次做错在哪。

做题范围：带 \* 的题和编程题必做，其余的挑一半左右。各章做到哪里，记在该章目录的 `README.md` 里。
