## 第 2 步：写代码（约 2 小时）

合上书，按下面的顺序写，每写完一个函数就运行一次测试：

1. 写构造函数（创建一个空的根节点）和析构函数（递归释放所有节点，可以自己写辅助函数）。
2. 写 `search`：在当前节点里用 `key.search(e)`（你第2章写的有序查找）找位置，没找到就进对应的孩子，同时维护 `_hot`。
3. 写 `insert`：search 失败后在 `_hot` 里插入关键码，并在对应位置插入一个空孩子，然后 `solveOverflow(_hot)`。
4. 写 `solveOverflow(v)`：孩子数超过 m 时，以 s = m/2 为界把 v 分成两半，v->key[s] 升到父节点（没有父节点就新建根），对父节点递归处理。
5. 运行 `tools/test.sh ch08_btree D22`。
