## 题目

所谓双向平方试探法，是平方试探法的一种拓展变型。具体地如图x9.2所示，在出现冲突并需要排解时，将以

```cpp
   { +12, -12, +22, -22, +32, -32, +42, -42, ... }
```

为间距依次试探。整个试探过程中，跳转的方向前、后交替，故此得名。186

图x9.2 双向平方试探法试证明，只要散列表长取作素数M = 4k + 3（k为非负整数），则：

a） 任一关键码所对应的查找链中，前M个桶必然互异（即取遍整个散列表）；①（提示：任一素数M可表示为一对整数的平方和，当且仅当M  1 (mod 4)）

b） 在装填因子尚未增至100%之前，插入操作必然成功（而不致因无法抵达空桶而失败）。
