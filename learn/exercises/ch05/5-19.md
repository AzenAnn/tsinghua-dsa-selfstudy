## 题目

参考图5.26（教材135页）和图5.27（教材135页）中的实例，考查对规模为n的完全二叉树（含满二叉树）的层次遍历。

a） 试证明：在整个遍历过程中，辅助队列的规模变化是单峰对称的，即

```cpp
   { 0, 1, 2, ..., (n + 1)/2, ..., 2, 1, 0 } （n为奇数时）或
   { 0, 1, 2, ...,  n/2, n/2, ..., 2, 1, 0 } （n为偶数时）
```

b） 非完全二叉树的层次遍历过程，是否也可能具有这种性质？为什么？
