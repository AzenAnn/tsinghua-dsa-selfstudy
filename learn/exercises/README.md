# 教材课后习题

《数据结构（C++语言版）》第 3 版全部 292 道课后习题，从教材 PDF 里逐题提取，一题一个文件：`learn/exercises/ch02/2-12.md` 就是第2章第12题。

- **每题文件里有**：题目原文、安排在哪一天、题型（编程 / 证明 / 分析）、是否必做、原书 PDF 页码。
- **必做规则**：原书没有用 \* 标出难题，这里规定编程题和证明题必做（184 道），分析、举例类选做（108 道）。
- **每天做哪几道**：写在每天指南的“练习”一节；每章的完整清单在 `learn/exercises/chNN/README.md`。
- **怎么写**：在题目文件的“我的解答”下面写；编程题的代码写在同目录的同名 `.cpp` 里（比如 `learn/exercises/ch02/2-12.cpp`），可以 `#include "dsa/..."` 用自己写的结构，用 `tools/run.sh learn/exercises/ch02/2-12.cpp` 编译运行。
- **对答案**：官方解答在原书里紧跟题目，页码写在每题文件开头。先自己做，做完再看，把差距写进“对照官方解答后的反思”。
- **进度**：`python3 tools/progress.py` 会把“我的解答”下面写了内容的题算作完成。

题目是用脚本提取的：个别数学符号（Ω、Θ、上取整、上标，如 0² 会显示成 02）和插图提取不出来，遇到看不懂的地方以原书为准。
