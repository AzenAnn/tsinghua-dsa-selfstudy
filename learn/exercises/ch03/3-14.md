## 题目

教材81页代码3.20中的List::selectionSort()算法，通过selectMax()在前缀子序列中定位的最大元素max，有可能恰好就是tail的前驱自然，此时“二者”无需交换。针对这一“问题”，你可能会考虑做些“优化”，以期避免上述不必要的交换，比如将 81

```cpp
      insertB( tail, remove(max) );
```

一句改为

```cpp
      if ( tail->pred != max ) insertB( tail, remove(max) );
```

a） 以序列{ 1980, 1981, 1982, ..., 2011, 2012; 0, 1, 2, ..., 1978, 1979 }为例，这种情况共发生多少次？

b） 试证明，在各元素等概率独立分布的情况下，这种情况发生的概率仅为lnn/n  0也就是说，就渐进意义而言，上述“优化”得不偿失。
